## 3. 不通过项

### 3.1 合入 main 后 `.ui-dialog` 的渐变变成错值

`components.css` 写的是 `background:var(--grad-card)`。

| | `--grad-card` 的值 |
| --- | --- |
| R05 所在基线 `281b4bc` | `140.026deg, #253229 6.17%, #17221C 93.83%`（对应 `29:7923`） |
| main（R02 修正后） | `to right, #253229 0%, #17221C 100%` |

`29:7923`（327×391.5）在 JSON 里是斜向渐变，main 上对应的 token 是 `--grad-card-diagonal-h391-5`（`140.03deg`）。git 自动合并不会报冲突，构建和现有用例也都能过，但确认框会变成横向渐变。

同样的改名也影响图标按钮：main 上 `--grad-icon-btn` 是 135°（228 处），横向那 46 处叫 `--grad-icon-btn-horizontal`。`.ui-icon-button` 默认取 135° 是对的（多数派），不用改 CSS；但文档要改，见 §3.3。

### 3.2 `.ui-chip` 文字色不对

文档称胶囊取自 `29:13686`。该节点文字 `29:13688` 的颜色是 `#B2DA9C`，main 上已有 `--text-profile-wallet: #B2DA9C`；CSS 用的是 `--text-primary`（`#E4EFD9`）。字体 400 10/12.1、高 28、圆角 14、内边距 10、间距 5、底 `#23362A` 都对。

### 3.3 `R05-result.md` 与实际不符的 4 处

1. 差距表写图标按钮“水平渐变”。那是 `35:3621`（首页页头）这个节点的值；合入后 `.ui-icon-button` 默认是 135°。应写明默认 135°、首页页头两枚由 R06 用 `--grad-icon-btn-horizontal`。
