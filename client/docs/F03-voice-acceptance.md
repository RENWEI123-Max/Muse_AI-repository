# F03 · C6 真实语音修复（任务 #48 / Issue #34）

仅修改 client 的 C6 聊天组件、样式、C6 测试及本文档；未修改 maugo/ 或 C2–C5 实现，未访问生产业务数据，未提交或推送 Git。

## 通过清单

- 麦克风：真实调用 getUserMedia；区分权限拒绝与设备/能力不可用。完整 Chromium 通过 CDP 设置拒绝，再授予 microphone 权限，真实采集虚拟麦克风音频，没有替换成功路径的媒体 API。
- 空录音：不足 0.5 秒有明确反馈；静音麦克风录制超过 1 秒也被拦截；静音测试断言上传请求为零。
- 上滑取消：显示取消状态、释放后提示取消；断言零上传、无试听资源及全部已采集麦克风轨道 ended。PCM 样本清空，预览 URL 在取消、重录、离开聊天时撤销。
- 真实录制：采集 PCM 编码 WAV，符合 B8 的 MIME/文件签名检查；时长由实际样本数量计算。发送前可试听、重录或取消，保留波形和面板过渡动效，沿用原型暗绿及气泡样式。
- 最长录制：完整 Chromium 实际持续录制 60 秒，自动停止进入试听；音频元数据断言大于 59 秒且不超过 60 秒，取消后无音频消息，测试通过。
- 断网：浏览器 offline 时保留录音、显示明确提示，零上传；恢复后可重试。另对上传请求注入网络失败，确认保留预览并可再次上传成功。
- 上传/播放：真实 POST /media/uploads 上传 WAV，再 POST /conversations/:id/media 发送；浏览器播放后 currentTime 增长；退出重进后通过鉴权读取音频，恢复可播放音频和真实 duration。
- 构建/开发：最终 npm run build 通过；npm run dev 由 Playwright 实际启动并完成浏览器访问。C6 聊天、图片/表情、历史和设置四项回归全部通过；补充静音、失败重试和麦克风释放两项语音测试通过。

## 失败清单 / 缺失证据

- 实体麦克风、iOS/Android 及 Safari 尚未实机验证；服务器上的通过项来自完整 Chromium 与虚拟音频输入。
- 没有取得设计源文件进行逐像素验收；已对照仓库 docs/c6-chat-open.png，保留配色、布局、工具栏和气泡风格。
- 若上传成功但发送媒体消息失败，重试会复用 mediaId；此时取消会清理本地录音，但 B8 没有提供媒体删除接口，无法由本次仅客户端修改保证清除服务器上未发送的上传文件。上滑取消发生在上传前，已验证零上传。需要 Smith 决定是否另开后端媒体清理任务。
