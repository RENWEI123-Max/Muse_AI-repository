# 帮助页韩文修复结果

任务 #85（Issue #69），验证日期：2026-11-13。

## 原因与修复

帮助页改为自助入口后，不再渲染现有 `helpNote`，导致其中的韩文“답장 10개”消失。新增帮助首页及 FAQ 文案又没有 `businessKo` 映射，`tr()` 按现有规则回退到英文；本地反馈提示和支持邮箱标签还直接写成了英文。

在帮助页恢复现有 `t('helpNote')`，补齐帮助首页和六条 FAQ 的韩文映射，并将该页的反馈提示、邮箱标签接入现有翻译。反馈按钮复用已有 `t('feedback')`。保留支持邮箱待 Smith 提供的占位符。不修改其他页面模板、全局回退逻辑或原有测试断言。

## 验证结果

- 原 D6 “Korean business screens keep user content intact” 完整通过，帮助页“답장 10개”断言通过，后续业务页断言也全部通过。
- 原 D8 十四种支持页状态回归通过。
- 新增 `tests/ko-help.spec.ts` 通过：检查帮助首页韩文、删除与反馈按钮、六条 FAQ 的问题及答案，以及切回英文后的说明和 FAQ。
- 最终一轮浏览器测试共 3 项，全部通过，无新增失败。
- `npm run build` 通过，包含资源校验、`vue-tsc --noEmit` 类型检查和 Vite 生产构建；单独类型检查亦通过。
- `git diff --check` 通过。

测试复用现有 `auth-server.mjs` 的隔离数据库机制，每次创建 `maugo_client_c2_test_<时间戳>` 新库后执行迁移和测试数据准备，业务读写仅指向新库；没有改动真实业务数据，没有删除数据库、修改密码或密钥。因默认端口被其他任务占用，验证时临时将启动器和测试中的端口统一替换为 3185/5285，测试断言保持原样；临时副本已移除。
