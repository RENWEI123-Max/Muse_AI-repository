## 离线原型核对和未通过清单

参考 `/root/MauGo-handover` 的手机壳交互版、全状态平铺版及内嵌韩语词典，实际打开离线手机原型核对主页面。首页已补对应图标、三组圆角面板、行间距和八个入口；语言选项、开关、范围弹层、确认弹层和动画沿用现有客户端样式。核对仍发现：

1. **全局资料隐私未通过。** B16 `maugo/src/posts.ts` 的可编辑权限是每张形象照；动态仅在 POST /posts 创建时可指定范围，未提供动态范围 PATCH。`/profiles/:id` 没有全局 visibility；B16 不能实现原型“整个资料仅自己可见”，也不包含在线状态、访问历史、隐私屏幕偏好的全套设置。没有伪造全局 API、批量隐藏资料或用本地状态代替服务端权限。需 Smith 决定将 D6 定义为形象照权限，还是补全全局资料契约后再验收。
2. **完整设置主页面未通过。** 账号安全/反馈只有明确未接通的入口说明，未冒充密码、安全锁或反馈投递已完成；帮助提供现有通信、领取和安全操作说明，关于展示版本。原型的退出/注销入口及后续流程未在此次 D6 交付，不应计作已完成的其他模块。需 Smith 确认后续账号模块的接入安排。
3. **推荐与真机触感未完成实际服务/硬件验收。** 推荐明确禁用并标注未接通；触感已接浏览器设备 API，但没有真实手机震动测试证据。系统字体不受影响。
4. **完整视觉/动效验收未通过。** 在线 Figma 无访问权限，本次没有访问 Figma，也没有伪造 Figma 验收。离线原型的隐私完整行项、通知分类（原型另含主页回复横幅、点赞、关注、声音）及完整账号动作与当前客户端仍存在差异，不能宣称逐项高保真通过。需后续补齐并恢复 Figma 访问后复核。

改动范围仅 client/：设置、语言文案接入和必要的 token 传递、测试及本文件/截图；其他业务组件只接入文案翻译与语言对应的日期显示，未重写其业务流程。未改 maugo/ 源码，未推送、合并或切换分支。
